# Replit Brief — Nassau County Town Pages for The Property Father

## What This Is
45 individual town pages for thepropertyfather.com. Each page is a unique landing page for a Nassau County town. All content is written and ready — see the attached file `nassau-town-pages.md`.

## What Needs to Be Built

### Page Structure
- **URL pattern:** `thepropertyfather.com/locations/nassau-county/[town-slug]`
- **Parent page:** `thepropertyfather.com/locations/nassau-county` (already exists)
- Each town listed on the Nassau County parent page should link to its dedicated town page

### For Each Page, Pull From the Document:
- **Title tag** (under "Title Tag:")
- **Meta description** (under "Meta Description:")
- **H1** (under "H1:")
- **Body content** — all paragraphs between the H1 and "Internal Links:"
- **Sub-headings** — lines in bold (between `**`) are H2s within the body content
- **Internal links** — listed at the bottom of each page entry

### Page Layout (match existing site design)
- H1 at top
- Body content with H2 sub-sections
- CTA section at bottom: "Ready to sell your [Town] home?" with phone number (516) 548-6558 and link to the cash offer form
- Phone number should be a click-to-call link: `tel:5165486558`

### Sitemap
- Add all 45 new town page URLs to the sitemap
- Ensure sitemap is accessible at `thepropertyfather.com/sitemap.xml`
- Set `<lastmod>` to today's date
- Set `<changefreq>` to monthly
- Set `<priority>` to 0.7

### Nassau County Parent Page Update
- Each town name button on `/locations/nassau-county` should link to its corresponding town page
- Example: "Baldwin" button → `/locations/nassau-county/baldwin`
